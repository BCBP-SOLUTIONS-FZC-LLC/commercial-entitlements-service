# Metric registry — commercial-entitlements

Generated by `make metrics-inventory`. Re-run after adding or renaming a metric.

## Tier 3: service-specific metrics (`commercial_entitlements_*`)

| Name | Type | Labels | Description |
|---|---|---|---|
| `commercial_entitlements_recompute_total` | counter | `cause`, `outcome` | One entitlement recompute operation. `outcome` ∈ `computed` (snapshot changed + written), `noop` (ENT-INV-6: set unchanged), `error`. |
| `commercial_entitlements_recompute_duration_seconds` | histogram | `cause`, `outcome` | Wall time of one recompute call (Postgres read + compute + optional write). |
| `commercial_entitlements_override_set_total` | counter | `limit_key` | One manual override written (set). |
| `commercial_entitlements_override_remove_total` | counter | `limit_key` | One manual override removed. |
| `commercial_entitlements_override_expire_total` | counter | — | One override expired by the override-expiry reconciler. |
| `commercial_entitlements_addon_grant_total` | counter | `limit_key` | One quota addon pack granted. |
| `commercial_entitlements_addon_remove_total` | counter | — | One quota addon pack removed by an operator (ENT-O5 DELETE). No `limit_key` label: the handler receives only `addonId`; resolving the limit_key would require an extra DB round-trip. |
| `commercial_entitlements_addon_expire_total` | counter | — | One addon pack expired by the addon-expiry reconciler. |
| `commercial_entitlements_drawdown_total` | counter | `limit_key`, `shortfall` | One drawdown committed. `shortfall=yes` when available quota was insufficient. |
| `commercial_entitlements_shortfall_raised_total` | counter | `limit_key`, `status` | One quota shortfall raised. `status` ∈ `auto_accepted`, `pending_approval`. |
| `commercial_entitlements_shortfall_resolve_total` | counter | `disposition` | One quota shortfall resolved (accepted or rejected). `disposition` ∈ `approve`, `reject`. |
| `commercial_entitlements_cache_hit_total` | counter | `kind` | One Valkey cache hit. `kind` ∈ `effective_set`, `plan`. |
| `commercial_entitlements_cache_miss_total` | counter | `kind` | One Valkey cache miss. |
| `commercial_entitlements_trial_assignment_total` | counter | `profile` | One trial profile assigned or updated by an operator (ENT-O3). `profile` ∈ `trial_specific`, `reduced_plan`, `full_plan`, `custom`. |
| `commercial_entitlements_duplicate_messages_total` | counter | `consumer`, `event_type` | A redelivered SQS message deduplicated by the inbox (processed_events). |
| `commercial_entitlements_unknown_event_acknowledged_total` | counter | `consumer`, `event_type` | A consumed event of an unrecognised type, acknowledged without processing. `consumer` matches the queue-name used for `duplicate_messages_total`. |
| `commercial_entitlements_consumed_event_rejected_total` | counter | `consumer`, `event_type`, `reason` | An inbound SQS event rejected before reaching the domain handler. `reason=schema_violation` means the ValidatingCodec check failed and the message was forwarded to DLQ. Drives the `CommercialEntitlementsConsumedEventSchemaViolation` alert. |
| `commercial_entitlements_billing_ref_conflict_total` | counter | `event_type`, `reason` | A Billing `TenantQuotaAddOnChanged{reason:purchase}` whose `billing_ref` is already held by another tenant's add-on pack. Nothing is granted and the event is acked (a retry cannot succeed). Drives the `CommercialEntitlementsBillingRefConflict` alert (B-8). |
| `commercial_entitlements_rls_violations_total` | counter | `violation_type` | A PostgreSQL row-level security policy violation (SQLSTATE 42501 + "row-level security" message) detected by the postgres adapter. `violation_type=cross_tenant_access`. Any non-zero value is a critical compliance signal — drives the `CommercialEntitlementsRLSCrossTenantAccess` alert. |
